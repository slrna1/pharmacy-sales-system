# Система управления продажами аптеки

## Описание

Учебный проект по разработке модуля управления продажами в аптеке.

## Функционал

* оформление продажи
* изменение статуса продажи
* проверка переходов статусов
* уведомления пользователя
* хранение истории

## Диаграммы

В проекте представлены UML-диаграммы:

* Use Case
* Class
* Sequence
* Activity
* State
* Deployment

## Технологии

* Java / Spring Boot
* PostgreSQL


Добавлена логика работы со статусами продаж.
